SUPPORT AND FEEDBACK

Contacts

TrackVerse is created and maintained by Vaibhav Pandey. Use the channels below for help with the Windows habit tracker, feedback, or privacy questions.

Email Vaibhav Pandey

For support and privacy questions, email vaibhavpandey.cs31@gmail.com.

Report a bug or request a feature

Use TrackVerse GitHub Issues. Include your TrackVerse version, Windows version, steps to reproduce the problem, and what you expected to happen. GitHub issues are public: remove personal information from screenshots and logs.

Privacy and your data

Read the Privacy Policy for local storage, optional Google backup, and deletion guidance. Never send passwords, Google tokens, OAuth configuration files, or private habit backups in a support request.
