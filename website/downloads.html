Release notes & checksums ↗

Windows, through Microsoft Store

TrackVerse is now available on Microsoft Store. Install the Store-distributed app without the unsigned MSI setup steps or changes to Smart App Control.

The Store supplies the currently approved version. The v2.0.0 update will appear after Microsoft completes certification and publication.

Android 2.0.0 APK

Download Android APK ↗

Android 7.0 or later. This is a debug-signed test build with Google sign-in; production Android signing is pending.

Moving from the Windows MSI?

Export a backup from your existing app before switching. Install TrackVerse from Microsoft Store, import your backup, and verify your trackers. The Store app has a separate installation identity.

Alternative: unsigned Windows x64 MSI. Signing information applies to this direct installer: code signing policy.

Use the same tracker on both devices

Sign in with the same Google account. Back up a tracker on your first device, then use Find my trackers on the other device and open it. Android Settings includes Create tracker for separate plans. Sync runs while TrackVerse is open; offline conflicts ask you to choose a version.

Validation: 46 Flutter, 29 desktop and 8 release-policy tests passed. Android live Google backup and discovery passed, and the owner confirmed both platforms syncing. Physical-device and clean-machine installer acceptance remain pending.

Install and get started

  1. Open the Microsoft Store listing using the button above, then choose Get or Install. For Android, download the APK from the Android section.
  2. Open TrackVerse after installation. Microsoft Store manages Windows app updates; keep Windows security protections enabled.
  3. Choose local setup, create your first habit, and set a daily target. Google backup is optional.
