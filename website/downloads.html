Before you install

This release is unsigned. Windows Smart App Control may block the installer or app. Keep Windows security protections enabled. Trusted signing is pending.

Code signing policy ↗

Already using TrackVerse?

Export a backup and quit the app, including its tray process. Run the MSI from the same Windows account and installation scope. The upgrade identity is preserved; clean-machine upgrade testing remains pending.

Windows x64 installers and an Android test APK are available. Linux is planned.

Use the same tracker on both devices

Sign in with the same Google account. Back up a tracker on your first device, then use Find my trackers on the other device and open it. Android Settings includes Create tracker for separate plans. Sync runs while TrackVerse is open; offline conflicts ask you to choose a version.

Validation: 46 Flutter, 29 desktop and 8 release-policy tests passed. Android live Google backup and discovery passed, and the owner confirmed both platforms syncing. Physical-device and clean-machine installer acceptance remain pending.

Install and get started

  1. Download the Windows x64 MSI installer using the button above. Release notes include the published checksums.
  2. Run the installer and open TrackVerse. Keep Windows security protections enabled; read the signing information before installing.
  3. Choose local setup, create your first habit, and set a daily target. Google backup is optional.
