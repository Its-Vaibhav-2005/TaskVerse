# TrackVerse 1.3.0

Minor feature release (Flutter build 5), upgrading from 1.2.1.

- Tracker settings no longer reserve a large blank area for a sheet preview.
  Long tracker lists load as you scroll.
- New trackers start their first Google Sheets backup in the background, with
  progress shown while cloud operations run.
- Typography changes apply consistently, save in order, and include a live
  preview, clear text-size controls, and a reset option.
- Added privacy policy and support links to Settings.
- Limited Google token refresh wait time so a stalled refresh can report an
  error while local data remains available.
- Existing SQLite data and the established per-user MSI upgrade identity are
  retained.
