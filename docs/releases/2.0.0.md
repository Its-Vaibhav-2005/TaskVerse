# TrackVerse 2.0.0

Native Android support joins the Windows app, using the same versioned Google Sheets backup journal. Android Settings now includes Create tracker and a tracker switcher. Pending edits in inactive trackers retry while the app is open. The Today headline includes a 21-day consistency curve.

## Downloads

- Windows x64: TrackVerse-Setup-2.0.0-x64.msi (unsigned).
- Microsoft Store submission: TrackVerse-2.0.0-x64.msix (unsigned Store input; not a direct-install package).
- Android: TrackVerse-2.0.0-debug.apk (debug-signed test build, Android 7+).
- SHA-256 checksums and package audit reports accompany the files.

Existing Windows MSI upgrade and MSIX Store identities are retained. MSIX and MSI are separate installations; use JSON export/import when moving between them. No Store submission is performed by this release. Trusted Windows signing and Android production signing remain pending.

## Use one tracker on Windows and Android

1. Sign in with the same Google account on both devices.
2. Create a tracker in Settings. On Android, open Sync → Back up this tracker. Windows creates its cloud tracker through Settings → New tracker.
3. On the other device, use Find my trackers and open that tracker. Creating another tracker with the same name creates a separate tracker.
4. Changes sync while TrackVerse is open and after resuming. Offline edits remain local. If both devices change offline, choose a version explicitly; previous snapshots remain backed up.

## Validation

- 46 Flutter tests, 29 desktop tests and 8 release-policy tests passed. Flutter analysis is clean, and the web build succeeded.
- Cross-platform integration executes both actual sync engines over a shared in-memory journal transport: Android creation → Windows edit → Android check-in → Windows readback.
- Additional tests cover offline conflicts, uncertain uploads, corruption, wrong-account protection and separate tracker storage.
- Google sign-in was confirmed working by the owner. A live Google API round trip between two installed platforms, physical-device testing, clean-machine installation/upgrade and Store certification remain pending.

The Android APK has no sample habits. Preview builds are separate development artifacts and are not included in this release.
