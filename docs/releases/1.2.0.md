# TrackVerse 1.2.0 — Daily targets and reminders

**Draft: not published. The trusted signed MSI is not available yet.**

This minor update adds compatible features to version 1.1.0. The release version
uses Major.Minor.Micro: **1.2.0** (Flutter build number **3**).

## Added

- Daily targets from 1–99 and progress such as 3/8 in today's habit cell.
- Increase or correct the count with + / − and Save progress.
- Per-habit reminders with an editable first time and repeat interval.
- Reminders on scheduled days until the daily target is reached or the day ends.
- A system tray menu to reopen TrackVerse or quit and stop background reminders.
- Counts and reminder settings included in SQLite, exports, and Google backups.

Existing habits default to a target of one; previous check-in history is retained.
Windows notifications require the app to be running and respect Windows settings.
Open TrackVerse again after restarting Windows; automatic startup is not enabled.

## Upgrade instructions (for the final signed MSI)

1. Export a TrackVerse backup before upgrading.
2. Quit TrackVerse, including the system tray process if reminders are enabled.
3. Run **TrackVerse-Setup-1.2.0-x64.msi** from the same Windows account, using the
   same installation scope as the existing app. No manual uninstall is needed.
4. Open TrackVerse and verify your habits, history, preferences, and trackers.

The upgrade configuration retains the released MSI family identity, application
ID, package name, product name, and default per-user scope. User data stays in the
existing Windows profile outside installation files. The database migration adds
daily targets, partial counts, and reminder settings without resetting habits.
